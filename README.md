# USB Laser Beam Profiler (версия 1.0, прототип)

Программа для **Windows 10/11** и USB-камер, определяющихся как обычное видеоустройство (UVC). Также работает на Linux с V4L2. Написана на Python, Tkinter, OpenCV, NumPy, SciPy и Matplotlib. **Проверена на синтетических кадрах, но не на вашей NEOCoolcam**: у разных USB-камер отличаются драйверы, форматы видеоданных и работа ручной экспозиции.

## Возможности

- Захват видео с USB-камеры (`ID 0, 1, 2...`), включая выбор DirectShow или Media Foundation в Windows.
- Автоматическое переподключение при потере видеопотока.
- Живое изображение, центральный крест и прямоугольная область анализа **ROI**, выделяемая мышью (правая кнопка — сброс).
- **Красная подсветка пикселей выше настраиваемого порога насыщения** и подсчёт их числа/доли в ROI.
- Отображение двух **проекционных профилей X/Y** (суммирование по ортогональной оси) и их аппроксимация гауссовыми функциями.
- **2D карта интенсивности** выбранной области, центр пятна, диаметры по уровню **1/e²**, показатель качества `R²`.
- Фоновый кадр: усреднение 16 кадров при перекрытом лазере.
- Ввод калиброванного масштаба в **мкм на пиксель ВЫХОДНОГО кадра**; без него программа честно показывает значения в пикселях.
- Экспорт исходного кадра PNG, 2D матрицы `.npy`, CSV профилей, JSON параметров и PNG графиков.
- Демонстрационный режим без камеры.

## Установка и запуск (Windows)

1. Установи **Python 3.10–3.12** с галочкой *Add Python to PATH*.
2. Распакуй архив и открой PowerShell в папке с `requirements.txt`.
3. Установи зависимости и запусти программу.

```powershell
py -3 -m pip install -r requirements.txt
py -3 usb_beam_profiler.py
```

В программе выбери ID камеры **0** и нажми **«Подключить»**. Если камера занята, закрой другие приложения, использующие её. Если программа не открывает нужную камеру, попробуй ID **1** или **2** и другой драйвер.

Для демонстрационного режима вместо обычного запуска выполни `py -3 usb_beam_profiler.py --demo`.

Если входная камера — HDMI/аналоговая, нужен соответствующий USB-видеозахват; если она не UVC и требует специального SDK, обычный OpenCV её может не открыть.

## Видеопоток и переподключение

Если камера не открывается или несколько чтений кадра подряд завершаются сбоем, программа повторяет попытки с паузой около двух секунд. При каждой попытке она использует тот же ID, драйвер и запрошенный размер кадра. Кнопки **«Остановить»** и **«Демо»**, а также закрытие окна отменяют попытки. Если операционная система присвоила камере новый ID, выбери его и снова нажми **«Подключить»**. Если драйвер задерживает открытие камеры или чтение кадра, переподключение ждёт завершения этого вызова.

При потере потока программа сбрасывает текущее измерение и тёмный кадр, включая незавершённую запись. После переподключения она повторяет явно заданные в текущем сеансе настройки экспозиции и усиления, если драйвер принимает эти запросы. При необходимости запиши тёмный кадр заново.

Под изображением указаны размеры полученных кадров: они могут отличаться от запрошенных. Показатель кадров/с отражает частоту поступления кадров в интерфейс. OpenCV читает поток в отдельном потоке выполнения, а интерфейс забирает самый свежий кадр из очереди.

## Как измерять

1. **Сначала обеспечь физическое оптическое ослабление.** Для непрерывного лазера на 780 нм мощностью 30 мВт с пятном 50–500 мкм нельзя полагаться на выдержку или красный индикатор пересвета для защиты сенсора. Требуются рассчитанные на 780 нм аттенюаторы, контроль остаточной мощности и защита глаз. **ПО НЕ ПРЕДОТВРАЩАЕТ ПОВРЕЖДЕНИЕ МАТРИЦЫ.**
2. Сними объектив (если используешь непосредственное измерение), проверь наличие IR-cut стекла. Не трогай сенсор пальцами.
3. По возможности отключи в настройках камеры: автоматическую экспозицию, усиление, гамму, WDR, подавление шума, цифровую резкость, авто-контраст. OpenCV не умеет отключать всё это для каждой камеры.
4. Выбери `Red`, если камера цветная и этот канал даёт самый чистый несатурированный профиль на 780 нм. Сравни также `Green`/`Gray`: отклик Bayer-фильтра и обработка драйвера могут отличаться.
5. Если есть дополнительная засветка, запиши «**Тёмный кадр**» после безопасного перекрытия лазера. Пока усредняются 16 кадров, ничего не меняй. Затем открой лазер в безопасно ослабленном режиме.
6. Выдели мышью ROI вокруг пятна — **с запасом хотя бы 1–2 радиуса пучка** от его краёв (чтобы попадали крылья и фон).
7. Если есть **красные пиксели** или предупреждение `НАСЫЩЕНИЕ`, прежде всего увеличь *оптическое ослабление*; затем проверь экспозицию. **Числа диаметра при пересвете скрываются как недостоверные.**
8. Если картина похожа на кольца или изображение имеет плоскую белую середину, не доверяй гауссовому фитированию. Устрани переотражения и насыщение.
9. Введи действительный масштаб в `мкм/пиксель`. **Не подставляй шаг пикселя сенсора из интернета, если камера выдаёт изображение с ресайзом/биннингом.** Калибруй по объекту известного размера в плоскости сенсора, либо достоверно установи шаг пикселя и режим кадра 1:1.
10. Сохрани результаты кнопкой **«Сохранить»**.

## Что измеряется математически

В предположении линейного отклика фотоприёмника и примерно гауссова распределения:

\[
I(x,y)=I_{bg}+A\exp[-2((x-x_0)^2/w_x^2+(y-y_0)^2/w_y^2)].
\]

Кривые X и Y получаются интегрированием яркости по другой координате. Каждая проекция фитируется функцией вида:

\[
F(x)=B+A_x\exp[-2(x-x_0)^2/w_x^2].
\]

**Диаметры: `D_x = 2*w_x`, `D_y = 2*w_y`**. Это **НЕ FWHM**. Значения переводятся в микроны умножением на калиброванный масштаб (мкм/px).

Сатурация определяется по порогу выбранного видеоканала **в том виде, в котором кадр пришёл из драйвера**. Видеопотоки с ограниченным диапазоном YUV или гаммой могут насыщаться *ниже 255* — при необходимости снизь порог (например, до 235). Флаг насыщения может не распознать скрытое насыщение до программной обработки. Даже хорошие `R²` не гарантируют линейности камеры.

## Пределы точности

- Для **50 мкм** нужны шаг пикселя существенно меньше диаметра (например, 2–3 мкм), корректная калибровка, отсутствие пересвета, нормальный сигнал/фон, без колец и программной нелинейности.
- Цветная камера с Bayer, автоматическими алгоритмами, MJPEG и гаммой даёт **приближённый** профиль. Точный научный профилометр требует линейного RAW/Mono сигнала и проверки по методу ножа.
- Фит не учитывает наклон осей эллипса: при повернутом эллиптическом пятне X/Y дают ширины проекций на оси матрицы, а не главные оси эллипса.
- Результат может быть искажён, если ROI обрезает пятно, если на матрицу попадает паразитный свет или если фильтр создаёт интерференцию.
- Установка программной экспозиции зависит от драйвера, а на Windows её единицы часто логарифмические. Программа сообщает, принял ли драйвер запрос, но это не гарантия физически установленной выдержки.

## Тестирование алгоритма

```bash
pip install pytest
python -m pytest tests -q
```

Тесты проверяют восстановление диаметра синтетической гауссианы, тёмный кадр и запрет на доверие пересвеченному профилю.
